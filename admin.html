Order settings

Prices and order options for the study notes order page. Changes show on the page and in the Google Form as soon as you save.

Admin key

From the Apps Script editor: run showAdminKey and copy the key from the Execution log.

Orders

Untick to pause ordering. The page keeps the free downloads and shows an “Ask on WhatsApp” button.

Price

Each pack shows its price (pages × price per page + binding), and the order shows the total. Each order's estimate is also saved in the sheet. Prices show only for print types with a price above 0.

Print types

Price in BDT per printed page (one side). With one type available, the page shows it as plain text; with more, the student picks one for each pack in the order, so one order can mix them (even the same pack in both). For packs with colour only where it matters, add a type such as “Colour figures, rest B&W” with its own price.

Binding

Price in BDT for each copy. Untick “available” to hide an option without deleting it. With one option left, the page shows it as plain text instead of a choice.

Pickup

Payment

For mobile banking, write the number and how to send, for example “01XXXXXXXXX (personal, Send Money)”. The page shows it when a student picks that method, with a copy button; the form lists it under Payment.

Department and batch

When not asked, every order is saved with the default. Options are separated by commas.

The Google Form follows: it gets a Department or Batch question while you ask for it.

Subjects and papers shown

Untick to hide a subject (all its packs) or one pack from the page and the form. Hidden packs cannot be ordered; nothing is deleted.
